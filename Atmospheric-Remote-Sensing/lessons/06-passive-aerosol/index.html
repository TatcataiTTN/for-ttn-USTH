What can we measure about aerosols?

Aerosols are suspended particles (dust, smoke, sea salt, sulfate). From space we can measure:

PropertyMeaningHow measured
AOD τa (e.g. at 550 nm)Aerosol amount in the column; τa = ∫ kext,aer(z) dz; proxy for PM2.5Reflectance — the most robust product
Ångström exponent αParticle size: α ≈ 0–0.5 coarse (dust, sea salt); α ≈ 1.5–2.5 fine (smoke, urban); fine-mode fractionSpectral dependence τ ∝ λ−α
Single-scattering albedo ω0AbsorptionUV (OMI UV Aerosol Index) or multi-angle/polarimetry
Type, refractive index, non-sphericityDust, smoke, sulfate, sea saltMulti-angle and polarimetric sensors: MISR, POLDER/PARASOL, 3MI
Layer height (ALH)Transport, radiative effectsO₂ A-band (TROPOMI), MISR (stereo), TIR for dust — see module 8
UV Absorbing Aerosol Index (UVAI)Qualitative detection of absorbing aerosolUV; useful above clouds
Example · computing α (numbers checked in Python)
  1. AOD(440) = 0.60; AOD(870) = 0.15
  2. α = ln(0.60/0.15) / ln(870/440) = 2.034 → fine particles
  3. AOD(550) = 0.60 × (550/440)−2.034 = 0.381

Principle of the retrieval

Measured quantity: top-of-atmosphere spectral reflectance ρ(λ, θ₀, θ, φ) = πI/(μ₀E₀) — possibly multi-angle and polarised. Aerosols scatter sunlight back to space, so they brighten a dark surface.

Simple modelρTOA(λ) = ρRayleigh + ρaer + T(λ) · ρsurf / (1 − S ρsurf)  ;  ρaer ≈ ω0 τa P(Θ) / (4 μ0 μ)
  1. Cloud screening and pixel selection (cloud-free, no sun glint, no snow).
  2. Estimate the surface contribution: dark ocean (≈ 0 in red/NIR); vegetation uses relations with the 2.1 µm band; bright deserts use “deep blue” 412 nm where the surface is dark.
  3. Look-up table (LUT): a radiative transfer model computes TOA reflectance for a set of aerosol models (size distribution, refractive index → ω₀, P(Θ)), AOD values and all geometries.
  4. Inversion: find the model + AOD that best match the measured multi-spectral (multi-angle) reflectance (least squares / OE) → AOD(λ), α, fine-mode fraction, (ω₀, type).

Passive versus active

Passive (MODIS, VIIRS, MISR, POLDER, TROPOMI, IASI)Active (CALIOP/CALIPSO, ATLID/EarthCARE)
Advantages• Wide swath → daily global coverage, km-scale horizontal resolution
• Long, mature time series (since 2000)
• Low cost, low power, many spectral bands
• Column properties (AOD, α, ω₀)		• Vertical profile (resolution ~30–60 m)
• Day and night; over bright surfaces and above clouds
• Depolarisation → particle shape (dust vs spherical)
• Fewer assumptions on the surface
Limitations• Little or no vertical information
• Daytime only, cloud-free only
• Strong dependence on surface reflectance (hard over deserts, snow)
• Ill-posed: uncertain type and ω₀; cloud contamination		• Very narrow footprint (“curtain” ~100 m), revisit ~16 days
• The lidar ratio must be assumed → AOD uncertainty
• Low S/N in daytime; attenuated by thick layers
• Expensive, high power
They complement each other
Passive gives the horizontal map and AOD; active gives the vertical structure (A-Train concept: MODIS + CALIOP).

Exam checklist — points you must mention

  • ≥3 properties: AOD, Ångström exponent / size (fine-mode fraction), ω₀ / absorption, type, layer height, UV aerosol index.
  • Measured: TOA spectral (multi-angle, polarised) reflectance; aerosols brighten dark surfaces.
  • Method: cloud mask → surface reflectance → LUT from RT model → best-fit AOD + aerosol model.
  • Passive: global coverage, no vertical info, daytime/cloud-free only. Active: profiles, day+night, narrow coverage.
Key points (Vietnamese summary from the guide)
  • Tính chất đo được: độ dày quang học AOD, số mũ Ångström (kích thước hạt), albedo tán xạ đơn ω₀ (hấp thụ), loại aerosol, độ cao lớp aerosol, chỉ số aerosol UV.
  • Đại lượng đo: hệ số phản xạ phổ (đa góc, phân cực) ở đỉnh khí quyển; aerosol làm bề mặt tối sáng lên.
  • Truy hồi: loại mây → ước lượng phản xạ bề mặt → bảng tra (LUT) từ mô hình truyền bức xạ → chọn AOD + mô hình aerosol phù hợp nhất.
  • Thụ động: phủ toàn cầu, nhưng thiếu thông tin thẳng đứng, chỉ ban ngày & trời quang. Chủ động (lidar): có profil, ngày-đêm, nhưng vùng phủ rất hẹp.
