Averaging kernel, in plain words

Retrieving a profile is like redrawing a picture from a blurred photo: you get a smoothed version of the true picture, and where the photo is too blurry you fill in with prior guesses (the a priori). The averaging kernel A tells you how blurry it is at each altitude.

DefinitionA = ∂x̂ / ∂x = G K  ;  G = (KT Sε−1 K + Sa−1)−1 KT Sε−1 (gain)
Consequencex̂ = xa + A (xtrue − xa) + G ε
  • Each row of A: the retrieved value at a level is a weighted average of the true profile at all levels. The width (FWHM) is the vertical resolution; the peak shows where the information really comes from.
  • Row area: ≈ 1 → the measurement dominates; ≈ 0 → the value is just the a priori.
  • DOFS = tr(A) = the number of independent pieces of information on the profile.
  • Column: a(z) = ∂VCD̂/∂n(z) (in DOAS: AMFlayer/AMFtotal); ideal is 1 at all altitudes.
Retrieval errorŜ = (I − A) Sa (I − A)T [smoothing] + G Sε GT [noise]

Ideal and realistic cases

(a) Ideal: A = I. Each kernel is a delta function equal to 1 at its own level and 0 elsewhere: the retrieval reproduces the true profile, independent of the a priori, with infinite resolution and DOFS = number of levels.

(b) Realistic: nadir ozone (GOME-2/OMI in UV 270–330 nm, or IASI at 9.6 µm):

  • Broad kernels (FWHM ~7–15 km) that overlap → vertical resolution ~6–10 km in the stratosphere, worse in the troposphere.
  • Peaks shifted from the nominal level; amplitudes < 1 (≈ 0.3–0.6).
  • DOFS ≈ 4–6 in the UV (≈ 1 for the troposphere), ≈ 3–4 for IASI: the stratosphere is known in ~3–4 thick layers plus roughly 1 piece of tropospheric information.
  • Poor sensitivity near the surface (Rayleigh scattering, strong O₃ absorption above, clouds) and above 50 km (little ozone) → those values come mostly from the a priori.

By contrast, limb ozone retrievals have narrow kernels (~2–3 km), DOFS ≈ 20–30, close to the ideal case in the stratosphere.

Observation: narrow kernels and accurate data → A → I and DOFS → number of levels. More noise or wider kernels → DOFS falls and the result relies more on the a priori. Try it in the averaging-kernel calculator. (DOFS = tr(A) also equals the sum of the eigenvalues of A; checked with numpy.)

Using AKs with a model: xm,smooth = xa + A (xmodel − xa), then compare with x̂; without this step a difference can come from sensitivity rather than from the model.

Worked example, quick Q&A and memory hooks

Worked example · one column measurement, two layers
  1. State x = (x₁, x₂), measurement y = x₁ + x₂ → K = [1 1]; a priori Sa = I (variance 1), noise Sε = 0.01.
  2. A = SaKᵀ(K Sa Kᵀ + Sε)⁻¹K = [1 1]ᵀ[1 1] / 2.01 ≈ [[0.50, 0.50], [0.50, 0.50]].
  3. DOFS = trace(A) ≈ 1.00 ≈ 1: one column measurement gives one piece of information. Each layer retrieval = half of the total → the layers cannot be separated.

Quick Q&A

Q: A level has an averaging-kernel row with area 0.2: meaning?
A: 80% of the retrieved value at that level comes from the a priori.
Q: Can an averaging kernel be negative?
A: Yes: oscillations appear when the retrieval sharpens a broad sensitivity.
Q: Why not use a very large S_a to reduce the a-priori influence?
A: The retrieval then amplifies noise and oscillates (ill-posed problem).
Q: What does a column averaging kernel > 1 above a cloud mean?
A: Enhanced light path above the bright cloud: the column is over-sensitive at that altitude.

Memory hooks

  • The averaging kernel is a blurred photograph: in an ideal photo every point is sharp (delta function); in a real one each point becomes a smear (broad kernel). DOFS = the number of points you can still tell apart in the blurred photo.Averaging kernel như ảnh chụp bị nhoè.

Exam checklist — points you must mention

  • Name: averaging kernel matrix A = ∂x̂/∂x; DOFS = trace(A).
  • x̂ = x_a + A(x − x_a) + Gε — retrieval = smoothed truth + a priori contribution.
  • Row width = vertical resolution; area = measurement contribution.
  • Draw delta functions (ideal) vs broad, overlapping, peak-shifted kernels (nadir O₃, DOFS ≈ 4–6).
Key points (Vietnamese summary from the guide)
