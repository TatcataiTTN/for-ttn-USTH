The map of the Big 12

3 key points

K1 · Photons → amount
Sources and sinks → light–matter → instrument → retrieval → interpretation.
K2 · Tool by target
Wavelength × geometry × platform; always give the reason.
K3 · Products are smoothed
Averaging kernel, DOFS, a priori, AMF dependence.

3 formulas

F1 · Beer–Lambert
I = I₀e−τ, τ = σNL; slant τ/cos θ; AOD, DOAS, lidar T².
F2 · RTE
dI/dl = −kextI + J; J = αB(T); attenuated background + attenuated emission.
F3 · Retrieval
x̂ = xₐ + A(x − xₐ) + ε; DOFS = tr(A); cost function J(x).

3 concepts

C1 · Lifetime
τ = 1/Σk; hours → hotspots; years → uniform.
C2 · Scattering regimes
x = 2πr/λ: Rayleigh λ⁻⁴, Mie forward peak, geometric Q → 2.
C3 · Two-λ trick
DOAS, DIAL, Ångström, AAI, O₂ A band.

3 principles

R1 · Photon budget
Absorption destroys; scattering redirects.
R2 · Kirchhoff + Planck
ε = α; thermal contrast; λmax = 2898/T.
R3 · Hydrostatic layering
p = p₀e−z/H; H ≈ 8.3 km; line width ∝ p.

How to answer: four steps

1
Name the Big-12 item the question asks about
2
Write the formula, define each symbol and the units
3
Insert numbers and give an order of magnitude
4
Add the reason in one sentence (physics, trade-off, limit)

Typical traps

  • Adding lifetimes instead of rates
  • One-way T in the lidar equation (it is T²)
  • Forgetting 1/cos θ and 1 km = 10⁵ cm
  • Comparing a model with a retrieval without the averaging kernel
  • Saying scattering destroys photons
