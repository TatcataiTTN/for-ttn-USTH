The averaging kernel matrix

DefinitionA = ∂x̂/∂x = G K  ,  G = (KTSε−1K + Sa−1)−1KTSε−1
Retrieval = smoothing + a priori + noisex̂ = xa + A (xtrue − xa) + G ε

Each row of A: the value at one level is a weighted average of the true profile; the FWHM is the vertical resolution and the peak shows where the information comes from.

Row area and DOFS

Row area ≈ 1
The retrieved value comes mostly from the measurement.
Row area ≈ 0
The retrieved value is close to the a priori.
DOFS = tr(A)
Number of independent pieces of information on the profile. DOFS = number of levels when A = I.
Ŝ = (I − A) Sa (I − A)T + G Sε GT

Column averaging kernels

a(z) = ∂VCD̂/∂n(z) = AMFlayer / AMFtotal; ideal is 1 at every altitude.

Ideal versus realistic (nadir O₃)

Features of nadir ozone retrievals

  • Kernels ~7–15 km wide, overlapping
  • Peaks shifted from the nominal level
  • Amplitudes < 1 (~0.3–0.6)
  • DOFS ≈ 4–6 (UV), ≈ 3–4 (IASI)
  • Near the ground: low sensitivity (Rayleigh, absorption above, clouds) → a priori
  • Above 50 km: little ozone, so sensitivity is lost
  • Limb: kernels ~2–3 km, DOFS ≈ 20–30

Using averaging kernels with a model

xm,smooth = xa + A (xmodel − xa)
  • Smooth the model profile with the satellite’s own A
  • Then compare with x̂ to remove smoothing and a priori effects
  • Without this step a difference may come from sensitivity, not from the model
